# AirControl - 隔空手势控制系统

AirControl 是一款基于摄像头手势识别的 Windows 桌面工具，让你无需触碰键盘鼠标，仅通过手部动作即可控制 PPT/WPS 演示、操控鼠标、或在屏幕上进行手写批注。

---

## 功能概览

| 模式 | 说明 |
|------|------|
| **演示模式** | 隔空挥手翻页、开始/结束幻灯片播放 |
| **鼠标模式** | 用手势控制鼠标移动、左键/右键点击 |
| **板书模式** | 全屏透明画布，单指书写、握拳清屏 |

---

## 系统要求

- **操作系统**：Windows 10 / 11
- **摄像头**：普通 USB 摄像头或笔记本自带摄像头
- **Python**：3.8+（运行源码时）

## 安装与运行

### 方法一：直接运行源码

1. 克隆或下载本项目到本地
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   - **GUI 版本（推荐）**：
     ```bash
     python -m app.main_ui
     ```
   - **命令行版本**：
     ```bash
     python -m app.main
     ```

### 方法二：打包为可执行文件

项目已配置 PyInstaller，执行：
```bash
python build.py
```
打包后的文件将输出到 `dist/` 目录。

## 使用说明

### 启动界面

运行 `main_ui.py` 后会弹出一个 320x240 的悬浮窗口，实时显示摄像头画面。窗口支持：
- **拖动**：按住左键拖动可移动窗口位置
- **设置**：点击左上角 ⚙ 按钮打开配置面板
- **关闭**：点击右上角 X 按钮退出程序

### 三种交互模式

程序支持三种模式，通过 **双手握拳** 进行循环切换：

#### 1. 演示模式（默认）

用于控制 PowerPoint 或 WPS 演示文稿。

| 手势 | 动作 |
|------|------|
| 手指并拢伸直，向右挥动 | 下一页 |
| 手指并拢伸直，向左挥动 | 上一页 |
| 手指并拢伸直，向上挥动 | 开始播放（F5） |
| 手指并拢伸直，向下挥动 | 结束播放（Esc） |
| 点赞（拇指竖起） | 切换到目标软件窗口 |
| 握拳 | 可自定义映射 |

> **防误触设计**：五指张开随意移动不会触发任何操作；手刚进入画面的前 0.3 秒内也不会触发动作。

#### 2. 鼠标模式

将你的手变成空中鼠标，屏幕上会显示一个大的圆形光标。

| 手势 | 动作 |
|------|------|
| 中指尖移动 | 控制光标位置 |
| 拇指捏合食指 | 左键点击（蓝色扩散动画） |
| 拇指捏合中指 | 右键点击（绿色扩散动画） |
| 剪刀手（食指+中指）上下移动 | 滚轮滚动（黄色箭头指示） |

#### 3. 板书模式

在屏幕上进行手写标注，适合教学或演示讲解。

| 手势 | 动作 |
|------|------|
| 仅伸出食指 | 书写/绘画 |
| 握拳 | 清空画布 |

## 配置说明

点击悬浮窗的 ⚙ 设置按钮，可调整以下参数：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 控制目标软件 | PowerPoint 或 WPS | WPS |
| 手势模型精度 | Lite（更快）/ Heavy（更准） | Heavy |
| 交互模式 | presentation / mouse / draw | mouse |
| 手势防抖（冷却） | 连续手势间的最小间隔 | 1000 ms |
| 鼠标灵敏度 | 鼠标模式下的跟踪灵敏度 | 40% |
| 画笔粗细 | 板书模式下的笔触宽度 | 4 px |
| 动作映射 | 各手势对应的具体操作 | 见 `config.json` |

配置会自动保存到 `config.json` 文件中。

## 技术栈

- **OpenCV**：摄像头采集与图像显示
- **MediaPipe**：手部 21 关键点检测与追踪
- **PyQt6**：GUI 悬浮窗口与设置面板
- **pywin32**：模拟键盘鼠标操作、窗口管理
- **NumPy**：光流法辅助追踪

---

## 手势识别原理

1. **手部检测**：使用 MediaPipe HandLandmarker 实时检测手部 21 个关键点
2. **光流补偿**：当 MediaPipe 暂时丢失手部时，自动启用 Lucas-Kanade 光流法进行位置估计，保证跟踪连续性
3. **姿态分类**：根据指尖与指节的相对位置，判断当前是握拳、并掌、张开还是点赞
4. **挥动检测**：记录手腕位置轨迹，当连续多帧的位移超过阈值时，判定为挥动手势并识别方向
5. **防抖冷却**：触发一次动作后进入冷却期，防止误触发

---

## 注意事项

1. **光线**：确保手部光线充足且均匀，避免背光
2. **背景**：复杂背景可能影响检测精度，尽量使用简洁背景
3. **距离**：手距离摄像头 30~80cm 效果最佳
4. **权限**：首次运行可能需要允许摄像头访问权限
5. **窗口切换**：「点赞」手势会自动查找并置顶目标软件窗口；若未找到则会尝试启动对应程序
